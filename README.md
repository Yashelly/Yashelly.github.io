# Robertas Burbo — CV

Personal CV website for Script Programming laboratory works 7-9.

Built from the FolioOne template by [BootstrapMade](https://bootstrapmade.com/folioone-bootstrap-portfolio-website-template/). Portfolio graphs were generated in MATLAB from LW3 and LW4.

Open the project folder in VS Code and use Live Server to preview the site.

LW9 styles are in `assets/css/custom.css`, loaded after the template and existing CV styles on all six pages.
